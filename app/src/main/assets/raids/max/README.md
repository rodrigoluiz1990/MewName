# Max battle portraits

Sprites downloaded from the existing app provider, Pokebattler:
https://static.pokebattler.com/assets/pokemon/256/

The source filename for each Pokemon ID is recorded in ../images.json.
Includes the bundled Max raid history and the Max recommendation roster.
Pokemon artwork belongs to its respective rights holders.

Portraits are displayed only in the Max battle details window, with no added
visual effects. Original sprite artwork and forms are preserved.
Bundled portraits are available without network access.
